I’m building a small Forge app called Admin Jump and I’m trying to validate whether the underlying problem is actually painful enough to solve. The problem I’m targeting is Jira Cloud administration being spread across many different settings screens when an admin simply wants to find a configuration object quickly. The current beta gives Jira admins one search interface across: custom fields workflows statuses issue types projects Search works by name, key, ID, or object type.
